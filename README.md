# **AWS DevOps CI/CD Project**

End-to-end DevOps project demonstrating Infrastructure using AWS, CI/CD automation, containerization, Deployment and monitoring on AWS.

### **Project** **Summary**

Built a production-style DevOps pipeline on AWS that automates infrastructure provisioning, application deployment, Docker, Kubernetes, Amazon CloudWatch .

### **Tech Stack**

1. AWS (EC2, EKS, VPC, IAM)
2. Docker
3. Kubernetes
4. GitHub

### **Architecture** 

Developer → GitHub → Docker → Docker Hub → EKS 

### **Key Features**

✅ Infrastructure provisioned on AWS 

✅ Dockerized application deployment

✅ Kubernetes orchestration on EKS

✅ Monitoring with AWS CloudWatch

### **Repository Structure**

├── AWS                                                                                                                                                           
├── docker/                                                                                                                                                       
├── kubernetes/                                                                                                                                                   
├── monitoring/                                                                                                                                                   
└── README.md

### **Deployment Workflow** 

Push code to GitHub --> 
Docker image is built and pushed --> 
Application is deployed to EKS --> 
Amazon CloudWatch monitor workloads
